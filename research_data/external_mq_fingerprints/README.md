# External MQ fingerprint research bank — 0.10.2 / HR069

This directory is the reproducible source registry for external MQ-series datasets reviewed for HazRob 0.10.2 / HR069.

## Current storage model

The repository stores the **source manifest and provenance**, while raw datasets remain at their canonical upstream hosts unless redistribution is explicitly verified. This avoids silently changing third-party data and makes every future import reproducible against a DOI, commit or published checksum.

Machine-readable registry: [`manifest.json`](./manifest.json)

Scientific review and compatibility notes: [`../../docs/EXTERNAL_MQ_FINGERPRINT_DATASETS_HR069.md`](../../docs/EXTERNAL_MQ_FINGERPRINT_DATASETS_HR069.md)

## Accepted MQ research sources

- `MQDS-001` — Gas Sensor Measurement: MQ2, MQ3, MQ5, MQ6, MQ7, MQ8, MQ135. Upstream GitHub is pinned to commit `a4f36dbcdcc650b9f7c7d105846ea1b6d69f76d4`; MIT license.
- `MQDS-002` — Food Freshness Electronic Nose Dataset: MQ2, MQ3, MQ4, MQ5, MQ6, MQ7, MQ8, MQ9, MQ135. It covers every installed HR069 MQ channel plus MQ6. The published Zenodo archive MD5 is `008b8ccb62d7a7d51ff9ffcfd698a1e5`. Raw mirroring is deferred until redistribution/license metadata is explicit.
- `MQDS-003` — UCI Gas sensor array low-concentration: includes MQ135 plus other MOS sensors, with known 50/100/200 ppb labels; CC BY 4.0. This is partial hardware overlap and is retained for low-concentration/time-series methodology, not as an eight-channel HazRob signature.

## Evidence boundary

External records are `RESEARCH_EXTERNAL` only. They can support:

- feature engineering and algorithm benchmarking;
- candidate/fingerprint priors;
- cross-sensitivity, mixture and drift research;
- validation of the software pipeline using data that were not generated by HazRob.

They cannot by themselves support:

- field safety decisions;
- authoritative occupational-exposure PPM;
- M4/HazRob-validated calibration status;
- claims that a third-party raw ADC value equals an HR069 `Rs/R0` value.

## Import rule for the next stage

Any imported/derived copy must keep the following provenance fields: source ID, canonical URL/DOI, source version or commit, original sensor names, raw units, source class/analyte, known concentration and unit when available, acquisition conditions, transform history and checksum. Missing information must remain null/unknown rather than being inferred.

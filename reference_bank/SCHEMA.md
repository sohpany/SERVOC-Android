# HISTORICAL REFERENCE ONLY — not the HR069-R1 publication destination

This older directory and the earlier `hazrob-approved-experiment/1` format remain for provenance only. Do not add any new accepted developer data here. The current 0.10.2 / HR069 submission exporter writes `hazrob-approved-experiment/3`, including exact experiment/session/capture lineage, content hashes and non-promotable review-state metadata.

New developer submissions may be staged under `research_data/hr069_developer_submissions/` on `release/hazrob-0.10.2-rc2` **only** after the app's developer/approval/lineage checks. Canonical analytical data remains under `research_data/hr069_analytical_library/` and requires separate scientific change control. A staged submission is not a Stable ChemCore update or M4 approval.

The earlier `/1` schema is historical, and must not be silently treated as the current `/3` schema.

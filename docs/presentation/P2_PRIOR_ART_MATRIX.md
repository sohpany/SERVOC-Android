## Prior-art conclusions for storyboard

1. **Mobile gas-sensing robots are established prior art.** HazRob should not frame the mere combination of robot + gas sensor as the invention.
2. **Electronic noses and multi-channel fingerprints are established prior art.** The candidate inventive value must be in the specific architecture, orchestration and decision governance.
3. **Open-Set gas recognition is established prior art.** HazRob’s potential differentiator is the coupling of OOD with controlled evidence tiers, fingerprint promotion, fail-closed outcomes and reportability constraints—not OOD in isolation.
4. **Multi-task classification/concentration prediction is established prior art.** HazRob’s interpretable joint inverse solver, source/evidence lineage and M0–M4 governance should be examined as combination-level differentiators.
5. **Industrial mobile inspection robots with gas sensing already exist commercially**, including Ex-certified systems. Patent framing must focus on specific analytical mechanisms rather than generic hazardous-area robotic inspection.
6. **Current HazRob limitations must remain visible:** no external OOD validation yet, incomplete M4 device calibration, current mixture guard is not full mixture deconvolution, and HR069 is not yet Ex-certified.

## Candidate P3 questions generated by P2

- Is the combination `controlled session state machine + adaptive next-measurement policy + multi-method chemical inference + evidence tier gate + fail-closed reportability` disclosed as a single architecture in prior art?
- Is HazRob’s `one-concentration joint inverse fit across heterogeneous evidence-tier response models` materially distinct from common per-sensor calibration or black-box classifier approaches?
- Is `lineage-aware evidence fusion` applied to chemical-sensor inference in a way that prevents double counting derived curves/fingerprints/QSPR sources?
- Is the specific `OOD acceptance → multi-channel fingerprint → M3 identity-only → M4 quantitative gate` decision chain disclosed elsewhere?
- Is the governed pathway `external paper/dataset → provenance grade → sensor mapping → runtime evidence object → auditable result envelope` patent-relevant or primarily software governance/practice?

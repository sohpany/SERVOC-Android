# HazRob 0.8 — دليل التوصيل والطاقة والحماية الكامل

> **الحالة:** مرجع توصيل ميداني عربي لـ HazRob 0.8  
> **ينطبق على:** DOIT ESP32 DEVKIT V1 + AI-Thinker ESP32-CAM + 8× MQ + 2× ADS1115 + ريليه 4 قنوات Active-LOW + BME/BMP + MAX4466 + IR + 2× MG995 مستمر.  
> **مصادر الحقيقة البرمجية:** `firmware/HazRob/Config.h`، `firmware/HazRob/Hardware.cpp`، `app/src/main/java/com/servoc/app/hardware/HazRobHardwareProfile.java`، `firmware/HazRob-CAM/HazRob-CAM.ino`.

## 1. قواعد الأمان

1. افصل البطارية قبل تركيب أو نزع أي سلك.
2. جميع الأنظمة تشترك في GND، لكن تيار السيرفو وسخانات MQ يعود مباشرة إلى نقطة STAR ولا يمر عبر لوحة ESP32.
3. لا تسمح بوصول 5V إلى أي GPIO في ESP32.
4. مخارج MQ التناظرية `AO` تذهب إلى ADS1115 فقط، ولا تذهب إلى ADC في ESP32 مباشرة.
5. لوحتا ADS1115 تعملان في مجال 5V، ويعبر SDA/SCL عبر محول مستوى I2C ثنائي الاتجاه.
6. لا تمرر تيار السيرفوهات أو سخانات MQ عبر منظم ESP32 أو أسلاك Dupont رفيعة.
7. حزمة البطاريات تستخدم خلايا متطابقة وBMS 2S مع balancing.
8. هذا الدليل يفترض لوحة ريليه 5V Active-LOW. إذا كانت اللوحة الفعلية 12V فلا توصل VCC/JD-VCC وفق هذا المخطط قبل مراجعة موديلها.
9. قبل أول تشغيل افحص عدم وجود قصر بين 5V/GND و3.3V/GND وطرفي البطارية.
10. ضع بطاقة تعريف على طرفي كل سلك متكرر.

## 3. منظومة القدرة

```text
4 × 18650 matched cells / 2S2P
        ↓
2S BMS with balancing (≥10A continuous, 15A preferred)
        ↓
F1 MAIN FUSE 10A — قريب من BMS+
        ↓
Main DC switch ≥10A
        ↓
Buck converter 6.0–8.4V → 5.0V
        ↓
5V STAR distribution point
```

### مكثفات الحماية المقترحة

- دخل الخافض: `470µF / 16V` إلكتروليتي + `100nF` سيراميكي بين VIN وGND.
- خرج 5V عند STAR: `2200µF / 10V Low-ESR` + `100nF`.
- قرب توزيع السيرفوهات: `1000–2200µF / 10V` + `100nF`.
- قرب خط MQ: `470µF / 10V` + `100nF`.

### فيوزات الفروع

| الفرع | الفيوز المقترح | الأحمال |
|---|---:|---|
| F2 DRIVE | 5A، ويُتحقق منه بقياس Stall | 2× MG995 |
| F3 MQ | 3A | 8× MQ + تغذية كونتاكت الريليه |
| F4 LOGIC/CAM | 2A | ESP32 + ADS + BME/BMP + MAX4466 + IR + ريليه logic + ESP32-CAM |

## 5. محول المستوى وI2C

نستخدم لوحة واحدة 4-channel bidirectional level shifter. نحتاج القناتين 1 و2 فقط.

| Level Shifter | التوصيل | اللون |
|---|---|---|
| LV | ESP32 3V3 | أصفر |
| LV GND | GND مشترك | أسود |
| LV1 | GPIO21 / SDA | أزرق |
| LV2 | GPIO22 / SCL | أبيض |
| HV | +5V | أحمر |
| HV GND | GND مشترك | أسود |
| HV1 | ADS1 SDA + ADS2 SDA | أزرق |
| HV2 | ADS1 SCL + ADS2 SCL | أبيض |

لا تضف Pull-up إضافية افتراضيًا؛ معظم محولات BSS138 ولوحات ADS/BME تحتوي Pull-ups أصلًا. عند مشكلة في الناقل يُقاس الخط أولًا.

## 6. ADS1115

### ADS1115 #1 — العنوان 0x48

- VDD → +5V
- GND → GND
- SDA → HV1
- SCL → HV2
- ADDR → GND
- ALRT غير مستخدم
- A0 ← MQ2 AO
- A1 ← MQ4 AO
- A2 ← MQ5 AO
- A3 ← MQ8 AO

### ADS1115 #2 — العنوان 0x49

- VDD → +5V
- GND → GND
- SDA → HV1
- SCL → HV2
- ADDR → VDD/5V
- ALRT غير مستخدم
- A0 ← MQ3 AO
- A1 ← MQ7 AO
- A2 ← MQ9 AO
- A3 ← MQ135 AO

### حماية/ترشيح AO الاختيارية

```text
MQ AO ── 1kΩ ──► ADS Ax
                 │
               100nF
                 │
                GND
```

لا تغيّر المسار التناظري بعد المعايرة من دون إجراء تحقق من المعايرة.

## 7. مجموعات MQ والريليه

### R1 / GPIO25 / ADS1 0x48

| الحساس | الطاقة | AO |
|---|---|---|
| MQ2 | +5V عبر R1 | ADS1 A0 |
| MQ4 | +5V عبر R1 | ADS1 A1 |
| MQ5 | +5V عبر R1 | ADS1 A2 |
| MQ8 | +5V عبر R1 | ADS1 A3 |

### R2 / GPIO26 / ADS2 0x49

| الحساس | الطاقة | AO |
|---|---|---|
| MQ3 | +5V عبر R2 | ADS2 A0 |
| MQ7 | +5V عبر R2 | ADS2 A1 |
| MQ9 | +5V عبر R2 | ADS2 A2 |
| MQ135 | +5V عبر R2 | ADS2 A3 |

جميع GND تبقى موصولة دائمًا. لا تستخدم DO. يمكن تشغيل R1 وR2 معًا لتشغيل الحساسات الثمانية إذا ظل خط 5V مستقرًا تحت الحمل.

## 8. لوحة الريليه

### جهة التحكم

| Relay input | ESP32 | اللون |
|---|---:|---|
| IN1 | GPIO25 | برتقالي |
| IN2 | GPIO26 | برتقالي |
| IN3 | GPIO27 | برتقالي — محجوز |
| IN4 | GPIO32 | برتقالي — محجوز |

يفضل `1kΩ` على التوالي في كل خط GPIO→IN. قبل توصيل ESP32، شغّل لوحة الريليه منفردة وقِس جهد IN غير الموصول. إذا كان أعلى من 3.3V استخدم واجهة ترانزستور/أوبتو مناسبة بدل التوصيل المباشر.

### جهة الكونتاكت

```text
5V MQ branch → COM1
NO1 → +5V لـ MQ2 + MQ4 + MQ5 + MQ8
NC1 unused

5V MQ branch → COM2
NO2 → +5V لـ MQ3 + MQ7 + MQ9 + MQ135
NC2 unused
```

استخدام NO يجعل سخانات MQ مطفأة عند فقد طاقة الريليه.

## 9. السيرفوهات

- Servo-L: إشارة GPIO18 — بنفسجي؛ +5V من F2؛ GND مباشر إلى STAR.
- Servo-R: إشارة GPIO19 — بنفسجي؛ +5V من F2؛ GND مباشر إلى STAR.
- ضع `1000–2200µF / 10V + 100nF` قرب نقطة توزيع السيرفوهات.
- لا تمرر تيار السيرفو عبر رجل 5V/VIN أو مسارات ESP32.

## 10. الحساسات المساعدة والكاميرا

| الوحدة | التوصيل |
|---|---|
| MAX4466 | VCC=3.3V، GND، OUT→GPIO36 |
| IR | VCC=3.3V أو خرج منطقي مؤكد ≤3.3V، GND، OUT→GPIO35 |
| BME280/BMP280 | 3.3V، GND، SDA→GPIO21، SCL→GPIO22، العنوان 0x76 أو 0x77 |
| ESP32-CAM | 5V + GND من F4 فقط؛ الاتصال بالماستر عبر Wi‑Fi |

عنوان الماستر: `192.168.4.1`، وعنوان الكاميرا: `192.168.4.2`.

## 11. تسلسل التركيب الأول

1. البطاريات + BMS + F1 + المفتاح + الخافض فقط؛ اضبط 5.00V قبل الإلكترونيات.
2. أنشئ نقطة STAR وأضف F2/F3/F4 والمكثفات.
3. ESP32 + Level Shifter + ADS1 + ADS2؛ تحقق من 0x48 و0x49.
4. أضف BME/BMP وتحقق من 0x76 أو 0x77.
5. اختبر R1/R2 بدون سخانات MQ.
6. صل AO الثمانية حسب الخريطة، مع GND مشترك وبدون DO.
7. صل +5V للمجموعتين عبر NO1/NO2 وراقب جهد 5V والتيار والحرارة.
8. أضف السيرفوهات بدون حمل ميكانيكي أولًا.
9. أضف MAX4466 وIR وESP32-CAM.
10. أي سخونة أو Reset/Brownout أو هبوط كبير في 5V أو طقطقة ريليه = افصل الطاقة واعزل الفرع.

## 12. ملاحظة BMS

مخطط أطراف BMS نفسه (`B+ / B- / BM / P+ / P-` أو غيره) يعتمد على موديل اللوحة الفعلي. لا تعتمد على ترتيب عام قبل قراءة الكتابة المطبوعة على BMS الذي سيُستخدم.
